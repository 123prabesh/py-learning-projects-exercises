# py-learning-projects-exercises
This is a repository of me learning the basics of Python.
This repository contains small Python programs created while learning and practicing Python fundamentals.
The focus of these exercises is to build a strong understanding of control flow, basic logic, and user interaction through simple command-line applications.


##Projects Included

- **Quiz (lists.py)**
    - A simple quiz program which quizzes you.
    - concepts-used: for loops, tuples, lits, sets, if statments


- **Number Guessing Game (my_random.py)**
    - A simple game where the user guesses a randomly generated number.
    - concepts used: loops, conditonals, input validation, random module

- **Order Items Project (ordering-projects.py)**
    - A simple ordering program that asks user what to order, calculates and outputs total price of the items ordered.
    - concepts-used: dictionary, if statements, membership operators, for loops, while loops

- **Rock Paper Scissors**
  - A command-line implementation of the classic game.
  - concepts used: conditional logic, user input handling, basic game rules.


 ## Purpose

These projects are learning exercises and are not intended to be production-ready applications.  
They serve as practice while building a foundation for backend and database-focused Python development.
